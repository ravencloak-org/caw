Log in from your agent

caw login is initiated from inside the MCP plugin running in your coding agent — not from this page.

  1. Open your agent (Claude Desktop, Cursor, Codex CLI, etc.) with the caw-watcher MCP enabled.
  2. Invoke the login tool. Your agent will open this site in your browser automatically.
  3. Complete the GitHub OAuth dance, pick your installations, and return to your agent.

If your agent doesn't show a login tool yet, update caw-watcher to the v0.2+ release.
